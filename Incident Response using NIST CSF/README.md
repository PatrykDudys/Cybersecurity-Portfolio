# DDoS Attack Incident Analysis – NIST CSF Framework

This project documents the analysis and response to a simulated Distributed Denial of Service (DDoS) attack against a hypothetical multimedia company’s  network. The goal of this project was to practise using and apply the **NIST Cybersecurity Framework (CSF)** to identify vulnerabilities, improve network defenses, and enhance future incident response capabilities.

---

## Project Summary
A flood of **ICMP packets (Ping Flood attack)** caused a two-hour network outage.  
The cybersecurity team investigated the cause, mitigated the attack, and implemented long-term prevention measures.  
Using the NIST CSF, I analyzed the incident through the following functions:
- **Identify** vulnerabilities and affected systems  
- **Protect** critical assets through improved controls  
- **Detect** abnormal network traffic  
- **Respond** with containment and neutralization  
- **Recover** normal operations and improve resilience

---

## Tools & Techniques Used
- Firewall Configuration and Hardening  
- Network Monitoring and IDS/IPS Integration  
- Log Analysis and Source IP Verification  
- Incident Response and Recovery Planning  
- NIST Cybersecurity Framework (Identify–Protect–Detect–Respond–Recover)

---

## Key Outcomes
- Implemented new firewall rules to limit ICMP traffic  
- Deployed network monitoring for traffic anomalies  
- Established incident response playbooks for future DDoS events  
- Improved recovery speed and reduced exposure time
