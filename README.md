Botium Toys Security Audit

This repository showcases a security audit performed on Botium Toys, a fictional toy company with an expanding online presence.

Scope
- Review IT-managed assets: employee devices, internal network, software systems
- Evaluate security controls and compliance (NIST CSF, GDPR, PCI DSS)
- Identify gaps and risks to sensitive data

Methodology
- Completed a risk assessment based on company assets and current security controls
- Evaluated security controls using a checklist
- Assessed compliance with relevant regulations
- Provided recommendations to improve security posture

Deliverables
- [Audit Report](audit-report.md) – Overview of methodology, findings, and risk assessment
- [Controls Checklist](controls-checklist.md) – Yes/No evaluation of controls
- [Recommendations](recommendations.md) – Suggested improvements

Skills Demonstrated
- Risk assessment
- Security control evaluation
- Compliance mapping (GDPR, PCI DSS)
- Professional audit documentation
