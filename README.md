# SQL Security Analysis Project

## Project Overview
This project demonstrates how SQL can be used to investigate potential security issues within an organization. By applying filters and conditions, I analyzed login attempts and employee records to identify suspicious activity and manage security updates for employee machines.

## Key Features
- **After-Hours Login Monitoring:** Identify failed login attempts outside business hours.  
- **Date-Specific Investigations:** Filter login attempts for specific dates associated with suspicious events.  
- **Geolocation Filtering:** Detect login attempts originating outside a designated country (e.g., Mexico).  
- **Employee Management:** Identify employees in specific departments (Marketing, Finance, Sales) and locations for system updates.  
- **Exclusion Filtering:** Isolate employees not in IT for targeted security actions.

## Purpose
The goal of this project is to showcase how SQL queries can help cybersecurity professionals:
- Detect suspicious login activity  
- Filter and analyze data based on multiple conditions  
- Prepare targeted security updates for employees  

This project uses two main tables: `login_attempts` and `employees`, applying logical operators and pattern matching to obtain actionable insights.
