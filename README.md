# 🛡️ Vulnerability Assessment – E-Commerce Database Server

## 📄 Project Brief
This project focuses on conducting a **vulnerability assessment** for a fictional e-commerce company.  
The company stores sensitive customer and business data on a **publicly accessible database server** used by remote employees.  
The goal of the assessment was to **identify potential threats**, evaluate **risk levels**, and **recommend remediation strategies** to strengthen the organization’s security posture.

---

## 🧭 Objective
- Identify security vulnerabilities related to the exposed database server.  
- Assess the likelihood and severity of potential threats.  
- Propose security controls and mitigation strategies aligned with best practices.  
- Improve the organization’s overall security posture and reduce risk exposure.

---

## 🧰 Tools & Frameworks Used
- 🧭 **NIST SP 800-30 Rev. 1** – Risk Assessment Guidelines  
- 🔐 **Principle of Least Privilege**  
- 🧱 **Defense in Depth**  
- 🪪 **AAA Framework** (Authentication, Authorization, Accounting)  
- 🧑‍💻 **MFA** (Multi-Factor Authentication)  
- 🧰 Network Security Concepts (Firewall, VPN, WAF)  
- 🛠️ Qualitative Risk Assessment (Likelihood × Severity)

---

## ⚠️ Key Risks Identified
- Data exfiltration by external attackers (e.g., SQL injection, unauthorized access)  
- Insider threats through misconfiguration or credential leaks  
- Networking attacks such as DDoS leading to downtime  
- Open ports and unnecessary services increasing attack surface  
- System failures causing data loss or service disruption

---

## 🛡️ Mitigation & Remediation
- Implement **strong access control** with MFA and RBAC.  
- Restrict network exposure using **firewalls**, **VPN**, and **WAF**.  
- Close unnecessary ports and **disable unused services**.  
- Integrate **backup and disaster recovery plans**.  
- Adopt a **DevSecOps** mindset with continuous monitoring and security testing.

---

## 📌 Outcome
This assessment provides **actionable recommendations** to secure the company’s database infrastructure, **minimize risks**, and **protect sensitive customer data**.
