TCPDump Log Analysis

This repository contains an analysis of TCPDump logs to identify network issues and problematic protocols within captured traffic.

---

Scope
- Analyze pre-captured TCPDump logs  
- Identify network anomalies and issues  
- Determine which internet protocols are causing problems  
- Provide insights into traffic patterns and potential bottlenecks  

---

Methodology
- Parsed TCPDump logs to extract key network traffic data (IP addresses, ports, protocols)  
- Conducted a detailed analysis to identify irregularities and errors  
- Correlated findings to pinpoint problematic protocols impacting performance  

---

Deliverables
- **Analysis Report** – Detailed findings and identified issues  
- **Protocol Summary** – List of affected protocols and traffic patterns  
- **Recommendations** – Suggested actions to resolve network issues  

---

Skills Demonstrated
- Network traffic analysis  
- Protocol troubleshooting  
- Log parsing and reporting  
- Problem identification and resolution
